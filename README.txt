Score Logic — Login da Direção e das Turmas

DIREÇÃO
Usuário: direcao
Senha: admin123

A direção pode:
- criar/editar/excluir turmas;
- selecionar o brasão diretamente dos arquivos do PC;
- criar o login de cada turma;
- alterar usuário e senha das turmas;
- criar atividades;
- lançar pontos positivos e negativos;
- excluir lançamentos;
- acompanhar ranking e histórico.

TURMAS
Cada turma possui um login próprio. Ao entrar, a turma pode:
- ver seu brasão;
- ver sua pontuação;
- consultar o ranking.

A turma NÃO consegue editar pontos, atividades, turmas ou usuários.

IMPORTANTE
As imagens são guardadas como dados no navegador para o teste. Para um TCC com vários computadores, o próximo passo seria usar um banco de dados e armazenamento de imagens no servidor.
